# Raja Rohit Maheshwari — Portfolio

A responsive, static portfolio website for Raja Rohit Maheshwari, Java Backend Engineer.

## Sections
- Introduction and professional summary
- Skills and technology stack
- Work experience
- Selected professional projects
- Education and recognition
- Certifications
- Contact links

## Run locally
Open `index.html` in a browser. No build step is required.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `raja-rohit-portfolio`.
2. Upload `index.html`, `styles.css`, and this README to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site. The URL will be shown in the Pages settings.

## Before making public
- Verify phone number and email are appropriate for public display.
- Verify certification names, issuers, and dates against the original certificates.
- Review project/client descriptions against employer confidentiality policies.
- Do not add confidential source code, internal screenshots, customer information, or employer documents.
